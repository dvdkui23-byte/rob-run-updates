# ROB RUN ANALYZER — Updates

Официальный канал доставки обновлений ROB RUN ANALYZER.

Это публичный репозиторий **только для готовых подписанных сборок**. Исходники приложения хранятся отдельно в приватном репозитории.

## Статус
Сервер обновлений создан, но **первый релиз пока не опубликован**. Файл `latest.json` появится только после сборки и подписания первого реального обновления.

## Формат публикации
- `latest.json` в корне ветки `main` — **подписанный** Ed25519 манифест.
- ZIP релиза в **Releases** (например, `rob_run_analyzer_3.4.1.zip`), содержащий `ROB_RUN_ROULETTE_ANALYZER.exe`.
- Версия, SHA-256 и точный HTTPS URL ZIP входят в подписанный манифест. Пакет нельзя изменять после подписи.

Проверка обновлений читает:

`https://raw.githubusercontent.com/dvdkui23-byte/rob-run-updates/main/latest.json`

**Не создавать вручную фиктивный `latest.json`:** приложение проверяет цифровую подпись. Публикуйте только файл, созданный `publish_update.py` с оригинальным закрытым ключом владельца.

**Никогда не загружать сюда:** исходный код, закрытые ключи подписи, ключи лицензирования, `license.dat`, `activation.json`, историю или базу AI пользователей.

Пока подписанный релиз не размещён и не проверен на Windows, автоматическое обновление у клиентов не работает.
